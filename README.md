# Proyecto de Ecotecnologías

Este repositorio contiene la documentación, investigación y desarrollo del **Proyecto de Ecotecnologías**. Su objetivo principal es investigar, diseñar y prototipar soluciones tecnológicas enfocadas en el desarrollo sostenible y la mejora comunitaria.

## Estructura del Proyecto

El proyecto está organizado de manera secuencial en las siguientes fases y áreas:

- **00_Dashboard**: Panel de control general, métricas y gestión del proyecto.
- **01_Base_Teorica**: Investigaciones, marcos teóricos y fundamentos de las ecotecnologías que se abordarán.
- **02_Trabajo_de_Campo**: Recolección de datos, evidencias, encuestas y trabajo práctico directo en las comunidades.
- **03_Diseno_y_Prototipado**: Diseños técnicos, bocetos, modelado y creación de los prototipos para las ecotecnologías propuestas.
- **04_Entregables_Finales**: Documentos de culminación, manuales de usuario y reportes de resultados finales.
- **99_Plantillas**: Formatos y plantillas estandarizadas para agilizar y unificar la documentación.
